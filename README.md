# Password Generator 🔐

## English
A secure password generator built in Python.

### Features
- Generates passwords with letters, numbers and symbols
- Saves a history of passwords generated during the session
- Input validation with error handling

### Usage
1. Run `python password_generator.py`
2. Choose option 1 to generate a password
3. Choose option 2 to view history
4. Choose option 3 to exit
